# hello-langgraph

A playground project to learn and experiment with [LangGraph](https://github.com/langchain-ai/langgraph).

## Overview

This project contains examples and experiments exploring LangGraph capabilities, including state management, checkpoints, tool integration, and human-in-the-loop workflows.

## Setup

### Prerequisites

- Python 3.13 or higher
- [uv](https://github.com/astral-sh/uv) package manager (recommended) or pip
- OpenAI API key

### Installation

1. Clone the repository:

   ```bash
   git clone <repository-url>
   cd hello-langgraph
   ```

2. Install dependencies using uv:

   ```bash
   uv sync
   ```

   Or using pip:

   ```bash
   pip install -e .
   ```

3. Create a `.env` file with your OpenAI API key:

   ```env
   OPENAI_API_KEY=your-api-key-here
   ```

## Notes
